# Data objects

A data object is a class mapped to a table. There were two ways to write one:

1. **Inherit from `ORMObject`** - the class itself gets `Create`, `Load`,
   `Save`, `Remove`, `Refresh`, events and status.
2. **Keep a plain class** - map it with the same attributes and use the static
   `ORM` facade (`ORM.Save(customer)`), so the class has no dependency on a
   base type.

## Mapping with attributes

```csharp
using System;
using Silvtek.ORMEngine;

[Serializable]
[Table("Customers", "Sales")]               // table, connection name
public class Customer : ORMObject
{
    [Column("CustomerID", DataType.Int32)]
    [PrimaryKey, DatabaseIdentity]          // key filled by the database identity
    private int id;

    [Column("Name", DataType.String, 100)]
    [Alias("CustomerName")]                 // extra name usable in queries
    private string name;

    [Column("Email", DataType.String, 200)]
    [Unique, Null]
    private string email;

    [Column("Status", DataType.Enum, typeof(CustomerStatus), EnumConversionType.ByName)]
    private CustomerStatus status;

    public Customer() { }
    public Customer(int id) { this.id = id; }   // key set before Load()

    public int Id { get { return id; } }
    public string Name { get { return name; } set { name = value; } }
    public string Email { get { return email; } set { email = value; } }
    public CustomerStatus Status { get { return status; } set { status = value; } }
}
```

Attributes could be placed on fields or properties.

| Attribute | Meaning |
|---|---|
| `Table(table)`, `Table(table, connectionName)`, `Table(table, connectionName, noCaching)` | Binds the class to a table and a named [connection](configuration.md#connections); `noCaching` turns [local caching](caching.md) off for this class |
| `Column(name, ...)` | Maps a member to a column. Overloads take a `DataType`, a length, a default value, or an enum type with its `EnumConversionType` |
| `PrimaryKey` | Part of the primary key |
| `DatabaseIdentity` | Value generated by the database (identity column) |
| `Sequence(typeof(MySequenceProvider))` | Value generated by a `SequenceProvider` you write |
| `Unique` | Value must be unique (`UniqueConstraintViolatedException`) |
| `Null` | Column accepts nulls |
| `Alias(...)` | Other names for the member in queries |
| `Preserve`, `Preserve(preserveNulls)` | Saving an object that was never loaded first loads the row, then puts back the values of `Preserve` members - so only those columns change. With `preserveNulls`, a null value is kept too |
| `Encrypt`, `Compress`, `RecordDigest` | See [Encryption](encryption.md), [Compression](compression.md), [Record digest](record-digest.md) |
| `ObjectFormatterProvider(typeof(...))` | For `DataType.Object` members (objects stored serialized): the `IFormatter` to use instead of the default `BinaryFormatter` |

`DataType` values: `Binary`, `Boolean`, `Byte`, `DateTime`, `Decimal`, `Double`,
`Guid`, `Int16`, `Int32`, `Int64`, `Single`, `String`, `Enum`, `Object`, `Xml`,
`Undefined` (let the engine decide).

`Column` also had a `ModeType` property (`ColumnModeType.IgnoreChanges`,
`ColumnModeType.ExcludeFromDigest`).

## A sequence provider

```csharp
public class OrderNumberSequence : SequenceProvider
{
    public override object GetNextNumber(object sender, MapMember info)
    {
        // Your own logic, e.g. read and increment a counter table.
        return OrderCounters.Next();
    }
}

[Table("Orders", "Sales")]
public class Order : ORMObject
{
    [Column("OrderNumber", DataType.Int64)]
    [PrimaryKey, Sequence(typeof(OrderNumberSequence))]
    private long number;

    [Column("CustomerID", DataType.Int32)]
    private int customerId;

    [Column("Total", DataType.Decimal)]
    private decimal total;
    // ...
}
```

## A plain class with the `ORM` facade

```csharp
[Table("Customers", "Sales")]
public class CustomerRecord        // no base class
{
    [Column("CustomerID", DataType.Int32), PrimaryKey, DatabaseIdentity]
    public int Id;

    [Column("Name", DataType.String, 100)]
    public string Name;
}

CustomerRecord c = new CustomerRecord();
c.Name = "Ada";
ORM.Create(c);                     // INSERT, Id is filled in

ORMObject bound = ORM.Instanciate(c);   // the bound wrapper: events, status, digest
```

`ORM.Instanciate(source)` returned the `ORMObject` that wraps a plain object;
`ORM.GetBoundObject(orm)` returned the plain object back.

## Mapping with an XML file

!!! warning "Unfinished in 1.7"
    XML mapping was designed and its parser exists, but in version 1.7 the
    loader throws an `ORMException` right after reading a map file, so classes
    mapped only by XML cannot be used. Attribute mapping is the working way.
    This section shows the design as it was. See
    [Known issues](known-issues.md#xml-mapping-throws-after-loading-the-map-file).

Instead of attributes, a class was meant to be mapped in an XML file named
after the class's full name - `<map-file path>\<Namespace.ClassName>.xml`, for
example `C:\MyApp\Mappings\MyCompany.Sales.Customer.xml`:

```xml
<dataMapping>
  <class fullname="MyCompany.Sales.Customer">
    <table name="Customers" connection-name="Sales" />

    <map member-name="id" column-name="CustomerID" datatype="Int32"
         is-key="True" accepts-null="False" sequential-type="DbIdentity">
      <queryAlias name="ID" />
    </map>

    <map member-name="name" column-name="Name" datatype="String"
         is-key="False" accepts-null="False" />
  </class>
</dataMapping>
```

`queryAlias` was meant to play the role of the `Alias` attribute (the 1.7
parser reads it but does not keep the names). Other child elements of
`<map>`: `encryptionProvider`, `compressProvider`, `sequenceProvider` and
`enumeration`; `<table>` also took `disable-cache`. This kept mapping out of
the class entirely - useful for classes from another assembly.
