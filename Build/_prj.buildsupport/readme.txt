this folder contains build support files.

* assemblyversion.net-x.x.txt 
(net-x.x means the .net version).
  - must contain a valid version for versioning the assembly. Please note that an assembly version change affects any binding if the assembly is strong signing. 

* buildnumber.txt
  - must contain a valid base version for the file version of the assembly. this version will be updated automatically each build.
